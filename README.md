# Library Management System - DBMS Project

A comprehensive Relational Database Management System (RDBMS) designed to automate and manage library operations efficiently, including book management, membership tracking, borrow/return processes, and fine calculations.

## 📌 Features
- *Book Management:* Add, update, and track available book copies.
- *Member Management:* Maintain detailed records of registered library members.
- *Borrow & Return System:* Issue books and manage return status.
- *Fine Calculation:* Automated fine tracking for overdue books.
- *Search & Filter:* Search books easily by title, author, or category.

## 🗄️ Database Schema & Architecture
The system consists of six main entity tables:
- Members
- Books
- Authors
- Categories
- Borrow
- Fines

## 🛠️ Tech Stack & Tools
- *Database Engine:* MySQL / MariaDB
- *Management Tool:* phpMyAdmin
